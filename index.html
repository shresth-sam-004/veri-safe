System Architecture & Tech Stack

Technical overview of the VeriSafe IoT Lifecycle Platform

Core Technologies Used

Frontend UI

Built using completely pure Vanilla HTML/CSS/JS. Implements advanced CSS Grid, custom animations, and a modern glassmorphism design system without heavy frameworks.

Backend API

Powered by Node.js and Express. Handles RESTful routing, CORS policies, secure data persistence, and encrypted asset management.

Vision AI

Integrates Tesseract.js for pure client-side Optical Character Recognition. Runs deep learning models directly in the browser to extract metadata.

Security & Cryptography

Secured via stateless JSON Web Tokens (JWT) for auto-auth, bcrypt for salt/hashing passwords, and simulated ECDSA logic for NFC handshake verification.

Data Flow Lifecycle

📷

1. Scan Receipt

Upload a photo of your purchase receipt or a digital GST invoice. Our Vision AI automatically extracts the product name, purchase date, and warranty details.

🛡️

2. Secure in Vault

Your asset is assigned a unique cryptographic ID and securely stored in your Immutable Vault, protecting its digital record.

📲

3. Tap to Verify

Write the digital record to a physical NFC tag. Anyone can tap the tag with their smartphone to immediately verify the item's authenticity.
